# Ручная проверка

Перед демонстрацией установите собственный ключ MapKit и соберите debug APK.

- Введите два адреса; проверьте, что пустые поля не позволяют перейти к тарифу.
- Вставьте адрес из буфера обмена и определите точку подачи по геолокации.
- Выберите точку на карте и вернитесь с адресом на главный экран.
- Выберите тариф, добавьте комментарий и детское кресло, подтвердите заказ.
- Проверьте смену статуса, уведомление и отмену заказа.
- Сверните приложение и откройте снова во время активного заказа.
- Откройте историю, загрузите маршрут и очистите список.
- Переключите светлую, тёмную и системную темы; перезапустите приложение.
- Проверьте отказ в разрешениях и работу без сети.

Сборка и стандартные тесты не заменяют эти проверки. Этот список — инструкция, а не отчёт об успешно пройденном тестировании.
